# Публичные материалы проекта

В README, документации, release notes, issue/PR и описании проекта не размещаются
ссылки скачивания или страницы релизов, включая GitHub Releases, внешние EXE/ZIP,
APK и адреса манифестов обновления. Не маскируйте их редиректами, сокращателями,
badges, QR, кодированием, HTML или изображениями.

Ссылки на исходники, авторов, лицензии и официальную техническую документацию
допустимы. Ссылка на GitHub REST Releases API в документации GitHub является
техническим источником, а не страницей скачивания приложения.

Перед публикацией проверяйте точные файлы выбранной ветки, README/docs, описания
PR и доступные связанные страницы. PR обновляет default branch только после
слияния. Изменение документации не означает публикацию сайта, Wiki или Pages.

Программные endpoint-адреса в реализации обновлений, их проверки и необходимые
публичные ключи не удаляются ради документальной очистки. Это не пользовательские
ссылки скачивания. Нельзя менять доверенные адреса, подписи или опубликованные
bytes как побочный эффект правки текста.

Пароли, токены, закрытые ключи, личные профили, сырые журналы, частная переписка,
локальные окружения и приватные инструменты тестирования в Git не входят.
