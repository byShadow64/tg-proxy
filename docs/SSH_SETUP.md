# Установка Helper через SSH

В Windows и Android сервер можно настроить из приложения. Это отдельное действие:
ввод IP готового Helper не запускает установку и не меняет режим частного сервера.

## Что потребуется

- VPS с Ubuntu/Debian и systemd, публичный IP и доступ root по SSH.
- Возможность сверить SSH-ключ в консоли хостинга.
- Для подключения зарегистрированных клиентов: свободные TCP/80 и TCP/443
  и доступный TCP/8444. Разрешите эти порты и во внешнем firewall хостинга.

## Установка из приложения

В Windows откройте **Настройки → Маршруты → Helper-server → Настроить VPS по SSH**.
Введите IP, SSH-порт, пользователя root и пароль. Перед началом установки
сверьте показанный SHA-256 отпечаток SSH-ключа с данными хостинга и подтвердите.
После установки и проверки сервера сохраните настройки клиента.

На Android откройте **Связь**, введите IP и нажмите **Подключить по IP**.
Если сервер ещё не настроен, выберите **Настроить сервер по SSH**:

1. Укажите SSH-порт и нажмите **Проверить ключ SSH**.
2. Сверьте отпечаток с консолью хостинга и нажмите **Подтвердить ключ**.
3. Введите пароль root и нажмите **Установить и зарегистрировать**.

При неожиданной смене ключа остановитесь и выясните причину. Доступ
зарегистрированным клиентам разрешает пользоваться сервером любой
зарегистрированной установке TG Proxy. Для существующего частного Helper
нужно отдельное согласие на смену режима.

Пароль используется в памяти текущей операции и не сохраняется в настройках.
Приложение передаёт встроенные файлы по SFTP; клонировать проект на VPS не нужно.
Подтверждённый SSH-ключ проверяется до передачи пароля.

## Порты и сертификаты

- **SSH:** заданный владельцем порт, обычно 22. Установщик не меняет sshd.
- **TCP/8444:** защищённый канал Helper. Повторная установка сохраняет его
  сертификат и токен.
- **TCP/443:** проверка сервера реестром зарегистрированных клиентов.
  Используется отдельный доверенный CA-сертификат с IP в SAN.
- **TCP/80:** выдача и продление этого сертификата через HTTP-01.

Установщик не заменяет посторонний веб-сервер на 80/443. Если порты заняты,
сначала освободите их или выберите другой VPS. Для короткоживущего IP-сертификата
служба продления должна оставаться включённой, а TCP/80 — доступным.

В режиме зарегистрированных клиентов действуют ограничения соединений,
размера сообщений и скорости. Переподключение не сбрасывает квоту.

## Ручная установка

Из корня исходников на VPS можно установить частный Helper:

```bash
sudo bash deploy_helper.sh
```

Чтобы включить зарегистрированных клиентов, нужны доверенные параметры реестра:

```bash
sudo bash deploy_helper.sh --registry-mode \
  --registry-url "$REGISTRY_HTTPS" \
  --registry-trust-spki "$REGISTRY_PUBLIC_SPKI" \
  --public-ip "$HELPER_PUBLIC_IP"
```

Это адрес и открытый ключ подписи из доверенной конфигурации, а не данные
случайного сервера. Для изменения режима ранее установленного частного Helper
дополнительно требуется `--allow-existing-private-upgrade`. Без этих параметров
обычная установка сохраняет частный режим.

## Если установка прервалась

Отмена прекращает локальную операцию, но уже выполненные команды на VPS могут
сохранить изменения. При потере соединения проверьте службы и доступ к серверу
перед повторной попыткой. Установщик создаёт резервную копию прежних файлов
и пытается восстановить их при ошибке; потерянный ответ сервера не подтверждает
успешный откат. Не удаляйте резервные копии, пока не проверите результат.
