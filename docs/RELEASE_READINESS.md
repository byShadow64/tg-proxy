# Готовность следующего выпуска

Планируемые версии: Windows 1.15.3, Publisher 1.0.4, Android 0.1.7-dev/code 9.
Текущий статус — подготовка; этот документ не является допуском к публикации.

- [ ] Выбрана окончательная ревизия и сохранён проверяемый снимок исходников.
- [ ] Завершены необходимые тесты и проверки готового EXE/APK.
- [ ] Проверены сохранность профилей, обновление и восстановление после ошибки.
- [ ] Проверены лицензии, зависимости, публичные тексты и отсутствие секретов.
- [ ] Сохранены окончательные assets, notes и SHA-256 без последующей подмены.
- [ ] Успешный CI относится к точному source SHA, workflow совпадают с default.
- [ ] Для Windows создан один immutable bundle и отдельный подписанный допуск.
- [ ] После публикации каждый канал проверен скачиванием окончательных файлов.

Неподписанный CI artifact, draft, очередь Actions и завершённая загрузка не равны
завершённому выпуску. Staging и инструментированные клиенты не публикуются.
Результаты и известные ограничения записываются в [PROJECT_STATE](PROJECT_STATE.md).
