# TG Proxy 1.15.3

Изменения:

- Прямые подключения разрешены только к адресам Telegram и поддерживаемым DC.
  Соединения с неверным протоколом отклоняются до обращения к внешнему серверу.
- Helper не следует WebSocket-переадресациям за пределы выбранного маршрута.
- Окно настроек остаётся видимым после закрытия главной панели.
- Обновлено оформление документации и адрес репозитория исходников.

Существующие настройки и серверные адреса обновлений сохраняются.
Android развивается отдельно и остаётся dev-версией.
