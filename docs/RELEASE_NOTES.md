# TG Proxy 1.15.3

Приложение и Publisher 1.0.4 переведены на самостоятельный репозиторий
`byShadow64/tg-proxy`. Подписанные серверные обновления и установленные профили
сохраняют прежнюю идентичность и адреса.

Прямые подключения ограничены адресами Telegram и поддерживаемыми DC. Неверный
протокол отклоняется до внешнего соединения; настроенные CF/Worker/Helper
остаются отдельными маршрутами. Helper не следует WebSocket-редиректам за
пределы выбранного назначения. Эти проверки включены в устанавливаемый Helper.

Исправлено восстановление настроек, открытых из трея без главной панели, после
отложенной перерисовки заголовка. Несохранённые значения и порядок окон сохраняются.

Сохранены подключение Helper по IP, явная SSH-настройка с проверкой ключа сервера,
диагностика, зелёная иконка, обе темы, RU/EN, прогресс обновлений и защищённый
установщик. Приватный Helper не открывается автоматически при обновлении.

Android остаётся отдельным dev-клиентом и не входит в Windows assets. Проверки
этого выпуска не обещают устранения конкретного VPN-инцидента, универсальной
совместимости сети или скорости медиа на непроверенных физических устройствах.
