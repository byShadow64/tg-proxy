# TG Proxy 1.15.5

Изменения:

- Автоматическая установка Windows требует подписанных метаданных. Клиент
  сверяет версию, размер и SHA-256 файла перед обновлением.
- Новый процесс подтверждает обновление после открытия локального порта.
- Ограничены размеры пулов, буферов и журналов. Исправлены иконка wheel и
  защита от одновременного запуска нескольких tray-процессов из исходников.
- В обычном журнале CLI и Docker скрыты секрет и ссылка подключения.
  Секрет для Docker можно передавать в файле.
- Обновлены шаблон Cloudflare Worker и ограничение подключений Helper
  на зарегистрированный ключ. Изменения применяются при обновлении серверного
  компонента.

Существующие настройки и серверные адреса обновлений сохраняются.
Android развивается отдельно и остаётся dev-версией.
