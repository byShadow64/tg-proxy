# TG Proxy 1.15.4

Изменения:

- Исправлена остановка HTTP/2 на Python 3.11 при одновременной отмене запроса
  и готовности соединения к передаче данных.
- Отмена ожидания ответа, свободного потока, записи и TLS-подключения
  больше не теряется при совпадении сетевых событий.
- Сохранены прежние таймауты, ограничения памяти и числа соединений,
  проверка сертификатов и исправления безопасности версии 1.15.3.

Существующие настройки и серверные адреса обновлений сохраняются.
Android развивается отдельно и остаётся dev-версией.
