# TG Proxy для Windows

Подготавливаемая версия — **1.15.3**, Windows 10/11 x64. Готовый файл
`TgWsProxy_windows.exe` работает без установленного Python.

## Подключение

1. Запустите TG Proxy и откройте его панель из трея.
2. Выберите **Открыть в Telegram** и подтвердите подключение. Либо скопируйте
   ссылку из приложения и откройте её в Telegram.
3. Оставьте TG Proxy работающим, пока используете это подключение.

Локальный адрес относится к этому компьютеру. После изменения порта или secret
повторно откройте актуальную ссылку. Никому не передавайте ссылку с вашим secret.
Перед выходом отключите этот прокси в Telegram или выберите другой доступный.

## Настройки

В панели доступны состояние, соединения, журнал и проверка маршрутов. Программа
поддерживает русский/английский языки, обе темы, автозапуск и работу в трее.
Настройки открываются перед главным окном. Закрытие панели оставляет прокси в трее;
для полной остановки используйте выход из меню приложения.

В Telegram можно добавить MTProto-прокси вручную: сервер `127.0.0.1`, порт и
secret из текущих настроек TG Proxy. Готовый Helper подключается по IP после
проверки сервера. [Helper](Helper.md) · [SSH-настройка](../SSH_SETUP.md).

## Обновления и портативный режим

Приложение проверяет доступную версию, показывает прогресс загрузки и проверяет
файл перед установкой. Повторный запуск активирует существующую панель.
Настройки сохраняются при штатном обновлении; ошибочная замена использует rollback.

Портативный режим выбирается параметром `--portable` или каталогом
`TgWsProxy_data` рядом с EXE. Сохраняйте весь этот каталог при переносе.
В обычном режиме профиль находится в пользовательских данных приложения.
