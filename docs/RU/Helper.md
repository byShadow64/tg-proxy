# Helper

Helper даёт TG Proxy дополнительный маршрут к Telegram через ваш VPS.
Если соединение работает без него, сервер настраивать не нужно.

## Подключение готового сервера

В Windows откройте **Настройки → Маршруты**. В блоке **Helper-server** введите
IP сервера, нажмите **Подключить сервер** и после проверки сохраните параметры.
Если приложение предложит перезапустить прокси, подтвердите перезапуск.

На Android остановите прокси, откройте **Связь**, введите IP и нажмите
**Подключить по IP**. Проверенные параметры сохраняются автоматически;
после подключения снова запустите прокси.

Для такого подключения владелец заранее включает доступ зарегистрированным
клиентам TG Proxy. Приложение проверяет сервер и получает временные параметры
доступа автоматически. Они обновляются, пока соединение используется.

Этот режим разрешает доступ всем зарегистрированным установкам TG Proxy.
IP частного сервера сам по себе не даёт к нему доступ и не меняет его настройки.

## Настройка своего VPS

Если сервер ещё не подготовлен, в Windows используйте **Настроить VPS по SSH**,
а на Android — **Настроить сервер по SSH** после проверки введённого IP.
Поддерживаются Ubuntu/Debian с systemd. Потребуются публичный IP, SSH-порт
и доступ root. До передачи пароля сверьте SSH-ключ с консолью хостинга.

Для режима подключения по IP нужны свободные TCP/80 и TCP/443, а также доступ
к TCP/8444. Учтите внешний сетевой экран хостинга. Приложение установит службы
и проверит подключение. Перевод существующего частного Helper в режим
зарегистрированных клиентов требует отдельного подтверждения владельца.

[Пошаговая SSH-настройка](../SSH_SETUP.md)

## Частный Helper

Настольный клиент сохраняет совместимость с частным сервером. В разделе
**Ручные параметры подключения…** укажите режим `tls-pin`, IP, порт, отпечаток
сертификата и токен, полученные от владельца. Обычный защищённый порт — `8444`.
Токен передаётся только после проверки сертификата и хранится в Windows с DPAPI.
Не публикуйте токен или полный конфиг.

Обычная ручная установка из исходников сохраняет частный режим:

```bash
sudo bash deploy_helper.sh
```

Скрипт создаёт сертификат, токен и службу `tg-helper.service`. Повторная установка
сохраняет существующие сертификат и токен. Открытый legacy-протокол по умолчанию
выключен; не включайте его без необходимости совместимости со старым клиентом.

## Если подключение не удалось

- Проверьте IP, доступность VPS и разрешённые порты.
- Убедитесь, что владелец включил подходящий режим доступа.
- После смены настроек сохраните их и перезапустите прокси.
- Если SSH-установка прервалась, сначала проверьте состояние сервера. Отмена
  на телефоне или ПК не означает, что удалённые команды были отменены.

Сведения о протоколах: [регистрация клиентов](../DEVICE_REGISTRY.md),
[подключение по коду владельца](../HELPER_PAIRING.md).
