# Безопасность и границы проверки

Документ описывает модель защиты исходников TG Proxy. Текущая подготовка:
Windows 1.15.3, Publisher 1.0.4 и Android 0.1.7-dev. Полный аудит новой сборки
не объявляется завершённым до записи фактических результатов в
[PROJECT_STATE](PROJECT_STATE.md). Это инженерная документация, не сертификация.

## Границы доверия

- Локальный прокси проверяет MTProto secret, инициализацию, допустимый DC и маршрут.
  Очереди, сообщения и соединения имеют пределы; ошибочный протокол закрывается.
- TLS проверяет доверие, имя и применимый pin. Ошибка проверки не разрешает HTTP,
  отключение проверки сертификата или произвольный WebSocket redirect.
- Helper — доверенный транспорт. Зарегистрированный ключ доказывает владение
  ключом установки, а не личность, HWID или подлинность приложения.
  Режим доступа всем зарегистрированным установкам включает владелец явно.
- Секрет старого private Helper не выдаётся через registry. Краткоживущий bearer
  lease хранится в памяти; его похищение остаётся риском до истечения срока.
- SSH проверяет точный host key до пароля. Установка сервера — отдельное действие
  владельца. Потеря ответа после удалённой команды не доказывает полный откат.
- Обновление проверяет подписанные метаданные, размер, SHA-256 и идентичность
  приложения. Android также проверяет APK signer и использует системное подтверждение.
- Приватные ключи и административные токены не входят в EXE/APK, исходники или
  release bundle. Публичные trust anchors не заменяют проверку конечного файла.

## Ограничения

Квоты ограничивают ресурсы, но не гарантируют защиту от всех злоупотреблений.
Создание множества ключей установки не является доказательством разных людей.
Шифрование канала не делает скомпрометированный доверенный сервер безопасным.
Приложение не является firewall для других процессов и не расшифровывает
содержимое сообщений Telegram.

Эмуляторы и анонимный handshake не доказывают работу реального аккаунта,
производительность медиа, поведение каждой сети или длительный Doze. Отмена
ожидания DNS не означает принудительную остановку системного resolver.

## Сообщение об уязвимости

Не публикуйте пароли, private token, ключи и полные ссылки с secret. Начните
с версии, ОС и безопасных минимальных шагов. Чувствительные подробности
передавайте через подтверждённый приватный канал владельца. Наличие private
vulnerability reporting сначала проверьте в интерфейсе репозитория.
