# TG Proxy

[English](docs/EN/README.md) · [Документация](docs/README.md) · [История изменений](CHANGELOG.md)

**Локальный MTProto-прокси для Telegram на Windows и Android.**

Работает на самом устройстве, подключает Telegram по ссылке и поддерживает собственный Helper-сервер.<br>
Для обычного запуска отдельный сервер не нужен.

</div>

---

- **Windows 10/11 x64:** панель управления, трей, автозапуск и портативный режим.
- **Android 8.0+:** локальный прокси, работа в фоне и остановка из уведомления.
  Android-клиент находится в разработке.
- Русский и английский интерфейс, светлая и тёмная темы, журнал и проверка маршрутов.

## Быстрый старт

1. Запустите TG Proxy. На Android нажмите **Запустить прокси**.
2. Нажмите **Открыть в Telegram**, выберите приложение и подтвердите подключение.
   Кнопка **Скопировать ссылку** позволяет открыть её самостоятельно.
3. Оставьте TG Proxy работающим, пока Telegram использует это подключение.

> Адрес `127.0.0.1` относится к текущему устройству. На другом телефоне или
> компьютере нужна своя копия TG Proxy. После смены порта откройте ссылку заново.
> Перед остановкой программы отключите этот прокси в Telegram.

**[Windows](docs/RU/README.windows.md)** · **[Android](android/README.md)**

## Helper

Helper — дополнительный маршрут через ваш сервер. Если Telegram работает без
него, оставьте Helper выключенным.

В Windows откройте **Настройки → Маршруты**, введите IP и нажмите
**Подключить сервер**. На Android откройте **Связь**, введите IP и нажмите
**Подключить по IP**. Если сервер ещё не настроен, приложение предложит
установку через SSH. Для неё нужны доступ владельца VPS и подтверждение SSH-ключа.

> Подключение по IP работает, когда владелец разрешил доступ зарегистрированным
> клиентам. Частный Helper не становится общедоступным после ввода его адреса.

**[Настройка Helper](docs/RU/Helper.md)** · **[Установка через SSH](docs/SSH_SETUP.md)**

## Как это работает

Telegram подключается к локальному MTProto-прокси, а TG Proxy выбирает доступный
маршрут к серверам Telegram, в том числе через WebSocket. Helper предоставляет
дополнительный маршрут. TG Proxy не является системным VPN.

Если соединение не работает, проверьте, что прокси запущен и в Telegram выбрана
его актуальная ссылка. На Android посмотрите раздел **Помощь**: ограничения фоновой
работы зависят от телефона. Ошибка отдельного маршрута не обязательно означает
обрыв всего подключения.
