# TG Proxy для Android

Локальный MTProto-прокси для Telegram на Android 8.0 и новее.
**0.1.7-dev** — версия для разработки и тестирования, которая ещё не отражает
финального качества приложения. Доступны русский и английский языки,
светлая и тёмная темы.

Для работы не нужны root-права на телефоне, VPN, аккаунт Telegram или доступ
к переписке. Прокси работает только на том устройстве, где он запущен.

## Быстрый старт

1. В **Обзоре** нажмите **Запустить**. Разрешите уведомления, чтобы видеть
   состояние прокси и кнопку остановки.
2. Нажмите **Открыть в Telegram**, выберите клиент и подтвердите подключение.
   Можно также **Скопировать ссылку** и открыть её самостоятельно.
3. Оставьте TG Proxy работающим. Остановить его можно в приложении или уведомлении.

Кнопки используют параметры уже запущенного прокси. После изменения порта
повторно откройте ссылку в Telegram. Адрес `127.0.0.1` относится к этому телефону:
для другого устройства нужна его собственная установка TG Proxy и ссылка.
Ссылку с секретом не следует пересылать другим людям.

После остановки TG Proxy отключите этот прокси в настройках Telegram или выберите
другой доступный. Статус «Прокси запущен» означает готовность локального сервера;
отправку сообщений и загрузку файлов проверяйте в Telegram.

## Helper

Helper — необязательный дополнительный сервер для соединения с Telegram.
Если Telegram уже работает, настраивать его не требуется.

Для готового сервера остановите прокси, во вкладке **Связь** введите IP и нажмите
**Подключить по IP**. После проверки и сохранения параметров запустите прокси.
Токен, отпечаток сертификата и одноразовый код вводить не нужно. Сохранённый
Helper можно отключить, сохранив его настройки.

Если Helper ещё не установлен, владелец сервера может открыть **Установку по SSH**.
Нужны сервер Ubuntu/Debian, права root и SSH-пароль. Независимо сверьте ключ сервера
до ввода пароля. Разрешение зарегистрированным клиентам и обновление существующего
Helper выбираются явно. Этот режим допускает все зарегистрированные установки
TG Proxy, а не только ваши устройства. Пароль остаётся в памяти; отмена установки
не гарантирует отката уже выполненных изменений на сервере.

Полученную ссылку Helper можно открыть через **Подключить по ссылке** в Связи или
Помощи. Перед сохранением приложение показывает предпросмотр и запрашивает
подтверждение. Ссылка Helper содержит IP сервера и отличается от локальной
ссылки подключения Telegram.

## Если связь не работает

- Проверьте, что прокси запущен, а Telegram использует свежую ссылку этого телефона.
- Проверьте сеть и выбранный режим Helper. Ошибка проверки сервера не отключает TLS.
- При разрывах после сворачивания проверьте фоновые данные и ограничения батареи
  для TG Proxy. Подсказки для Samsung и Xiaomi находятся во вкладке **Помощь**.
- В **Журнале** неудача отдельного маршрута ещё не означает общий отказ:
  приложение может подключиться другим путём. Предупреждение о handshake также
  может означать старую запись прокси или неподходящий протокол.
- При медленном видео сравните другой файл и Wi-Fi с мобильной сетью. Для сообщения
  о проблеме укажите версию, модель телефона, сеть, состояние Helper и журнал
  без секретов.

Android может ограничивать фоновую работу; поведение зависит от модели телефона
и сети. Приложение не меняет системные ограничения самостоятельно.

## Обновления и данные

В **Помощи → Обновления** доступна ручная проверка. По умолчанию включены
автоматическая проверка примерно раз в сутки и загрузка только по безлимитному
Wi-Fi. Android может отложить фоновую задачу. Ручная загрузка использует текущую
сеть, включая мобильную.

После проверки APK нажмите **Установить обновление** и подтвердите установку
в Android. Если система запросит разрешение источника, вернитесь после него
в приложение и повторите установку. Удалять старое приложение не нужно.
100% загрузки ещё не означает завершение установки.

У 0.1.5-dev и более ранних версий нет встроенного обновления: первую версию
с этой функцией устанавливают вручную поверх старой, с той же подписью.
Обновления не требуют GitHub-токена. Подробнее — [об обновлениях](docs/ANDROID_UPDATES.md).

Настройки защищены Android Keystore и AES-GCM; резервное копирование профиля
отключено. Журнал копируется только вручную. Скриншоты разрешены: перед отправкой
убедитесь, что на них нет паролей, личных данных и ссылок с секретом.
