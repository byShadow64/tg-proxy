# TG Proxy для Android

Локальный MTProto-прокси для Telegram на Android 8.0 и новее.
Текущая версия — **0.1.7-dev / code 9**. Это версия для разработки
и тестирования, которая ещё не отражает финального качества приложения.
Точный артефакт, выполненные проверки и ограничения — в
[состоянии проекта](../docs/PROJECT_STATE.md).

Интерфейс доступен на русском и английском языках, в светлой и тёмной темах.
Для запуска не нужны root-права на телефоне или VPN. Приложение не запрашивает
аккаунт Telegram, код входа или доступ к переписке.

## Подключить Telegram

1. В **Обзоре** нажмите **Запустить** и разрешите уведомления.
2. Нажмите **Открыть в Telegram**, выберите приложение Telegram и подтвердите
   подключение. Либо нажмите **Скопировать ссылку** и откройте её самостоятельно.
3. Оставьте TG Proxy работающим. Остановить его можно в приложении или кнопкой
   **Остановить** в уведомлении.

Кнопки ссылок используют параметры работающего прокси и доступны только после
его запуска. Надпись «Прокси запущен» означает, что локальный сервер готов;
работу соединения и доставку сообщений проверяйте в Telegram.

Адрес `127.0.0.1` относится к этому телефону. На другом телефоне нужно запустить
свой TG Proxy и получить его собственную ссылку. Не пересылайте ссылку с секретом
прокси другим людям. После изменения порта заново откройте ссылку в Telegram.
После остановки TG Proxy отключите его в настройках Telegram или выберите другой
доступный прокси.

## Подключить Helper

Helper — дополнительный сервер для соединения с Telegram. Если Telegram уже
работает через TG Proxy, настраивать Helper не обязательно. Для готового сервера:

1. Остановите локальный прокси.
2. Во вкладке **Связь** введите IP сервера и нажмите **Подключить по IP**.
3. Дождитесь проверки и сохранения параметров, затем запустите прокси.

Приложение получает и проверяет параметры автоматически. Вводить токен,
отпечаток сертификата или одноразовый код не нужно. Подключение имеет кнопку
отмены и ограничение времени; сворачивание приложения само по себе его не отменяет.

Сохранённый Helper показан отдельно. Его можно отключить или включить, сохранив
изменения. У ранее настроенного частного Helper скрытые параметры сохраняются
при переключении и смене локального порта. Ссылка **Helper** содержит только IP
сохранённого сервера; она не является локальной ссылкой подключения Telegram.

Если готового Helper на сервере нет, владелец может отдельно открыть **Установку
по SSH**. Для неё нужны права root на сервере Ubuntu/Debian и пароль SSH.
Перед вводом пароля нужно независимо сверить SSH-ключ сервера. Разрешение
доступа зарегистрированным клиентам и обновления существующего Helper выбирается
явно, для конкретного сервера. Такой доступ разрешает использовать Helper всем
зарегистрированным установкам TG Proxy, а не только вашим устройствам.
Пароль используется только в памяти.
Отмена установки не гарантирует откат уже выполненных изменений на сервере.

## Открыть полученную ссылку

В **Связи** или **Помощи** выберите **Подключить по ссылке** и проверьте
предпросмотр. До подтверждения приложение ничего не подключает и не сохраняет.

- `tgproxy://helper?ip=…` подключает Helper после обычной проверки сервера.
- Внешняя ссылка Telegram открывается в Telegram и не заменяет настройки Helper.
- Для подключения Telegram к этому телефону используйте **Открыть в Telegram** или
  **Скопировать ссылку** в Обзоре.

Секрет в предпросмотре скрыт. Скопированная локальная ссылка помечается как
конфиденциальная; приложение не записывает её в журнал.

## Если не удаётся подключиться

Во вкладке **Помощь** есть короткий порядок запуска, пояснение про Helper,
подсказки для проблем со связью, видео и работой в фоне. Дополнительные детали
можно раскрыть, когда они нужны.

- Проверьте, что TG Proxy запущен, а в Telegram выбрана актуальная ссылка этого
  телефона. Старый порт или секрет могут не соответствовать текущим настройкам.
- Проверьте сеть и выбранный режим Helper. Ошибка проверки сервера не отключает
  защиту TLS и не разрешает небезопасное соединение.
- Если связь пропадает после сворачивания или блокировки экрана, проверьте
  уведомления, фоновые данные и ограничения батареи именно для TG Proxy.
  Для Samsung и Xiaomi подсказки находятся в Помощи; названия пунктов зависят от
  версии системы. Приложение не меняет эти ограничения самостоятельно.
- Посмотрите **Журнал**. Сообщение о неверном handshake может указывать на старую
  запись прокси или неподходящий протокол; оно не устанавливает причину однозначно.
- Неудачная попытка отдельного маршрута ещё не означает, что весь прокси
  недоступен: приложение может подключиться другим путём. Такие попытки теперь
  показываются как информационные события; отказ всех доступных путей остаётся
  предупреждением. Проверяйте отправку сообщений и загрузку файлов в Telegram.
- Если видео загружается медленно, сравните другое видео и, по возможности,
  Wi-Fi с мобильной сетью. Для обращения приложите версию TG Proxy, модель
  телефона, тип сети, состояние Helper и журнал без секретов. По одной скорости
  или записи о маршруте нельзя определить виновника задержки.

Android может ограничивать фоновую сеть. Проверки на эмуляторе не гарантируют
поведение конкретной модели телефона, сети или длительного режима Doze.

## Данные и обновление

Настройки защищены Android Keystore и AES-GCM; резервное копирование профиля
отключено. Журнал содержит ограниченный набор технических событий и копируется
только вручную. Скриншоты разрешены: перед отправкой проверьте, что на них нет
личных данных, паролей или ссылок с секретом.

В **Помощи → Обновления** можно проверить новую версию вручную. По умолчанию
включены автоматическая проверка примерно раз в сутки и загрузка APK только по
безлимитному Wi-Fi. Android может отложить фоновую проверку из-за сна или батареи.
Ручная загрузка использует текущую сеть, в том числе мобильную.

После загрузки и проверки файла нажмите **Установить обновление** и подтвердите
установку в окне Android. Если система попросит, разрешите установку из TG Proxy,
вернитесь в приложение и повторите нажатие. Удалять прежнюю версию не нужно.
100% загрузки означает только получение файла, а не завершение установки.

У **0.1.5-dev и более ранних версий** встроенного обновления ещё нет: первую
версию с этой функцией нужно установить вручную поверх старой APK, с той же
подписью. Автоматический запуск прокси после включения телефона не добавляется.
Версия приложения показана в Помощи. Подробнее — [об обновлениях Android](docs/ANDROID_UPDATES.md).

Исходники Android входят в самостоятельный проект
[byShadow64/tg-proxy](https://github.com/byShadow64/tg-proxy).
Обновления приложение проверяет на отдельном сервере по подписанным метаданным;
доступ к GitHub и личный GitHub-токен на телефоне не требуются. Пакет приложения
и подпись сохранены, поэтому новую APK устанавливают поверх прежней без удаления
профиля. Готовность конкретной сборки и фактические проверки смотрите в состоянии
проекта.
