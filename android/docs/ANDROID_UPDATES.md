# Обновления Android

Встроенное обновление доступно с 0.1.6-dev. Для 0.1.5-dev и более ранних версий
первое обновление устанавливают вручную поверх старой APK, с той же подписью.
Это остаётся dev-каналом и не превращает приложение в стабильную версию.

## Проверка и установка

Откройте **Помощь → Обновления**. Можно проверить новую версию вручную,
прочитать краткий список изменений и загрузить APK. Приложение показывает
ход загрузки, затем проверяет файл и подпись.

По умолчанию включены два параметра:

- **Автоматически проверять** — фоновая проверка примерно раз в сутки и при
  открытии приложения, если подошло время. Проверка может использовать мобильную
  сеть. При отключении автоматические задания отменяются; ручная проверка остаётся.
- **Автоматически загружать по безлимитному Wi-Fi** — загрузка только при
  включённой автоматической проверке и Wi-Fi, который Android считает безлимитным.
  Лимитный Wi-Fi не подходит. VPN может скрывать тип сети; тогда загрузка ждёт.
  Ручная загрузка использует текущее подключение и может расходовать мобильный трафик.

Автоматическая загрузка прекращается, если сеть или настройки перестали подходить.
После неудачной автоматической попытки приложение ждёт не менее 30 минут.
Постоянного опроса и автоматической установки нет. Android может отложить фоновые
задания из-за Doze или низкого заряда. Обновление не включает запуск прокси
после перезагрузки телефона.

После загрузки и проверки нажмите **Установить обновление**. Если Android запросит
разрешение установки из TG Proxy, предоставьте его самостоятельно, вернитесь
в приложение и повторите нажатие. Затем подтвердите системный диалог установки.
Удалять прежнее приложение не нужно: настройки сохраняются при совместимой подписи.
После замены APK снова откройте TG Proxy и проверьте состояние прокси.

Загрузку и проверку можно отменить. Отменённую установку можно повторить с уже
проверенным APK. 100% загрузки и открытое окно установщика не означают успех.
При отключённых уведомлениях карточка обновления остаётся в приложении.

## Проверки безопасности

Приложение использует отдельный подписанный Android dev-канал. GitHub-токен
пользователя не требуется. TLS, подпись метаданных, размер и SHA-256 файла,
пакет, версия и исходный сертификат APK проверяются до установки. Перенаправления,
неверный сертификат и изменённый файл отклоняются; небезопасного обхода нет.

Сохраняется наибольшая подтверждённая версия и её хеш. Более старая версия
и другие байты с тем же номером не принимаются. Незавершённый файл не становится
готовым APK. Debug/testOnly APK не подходят для этого канала. Не очищайте данные
приложения ради обхода этих проверок.

Обновление завершает системный
[PackageInstaller](https://developer.android.com/reference/android/content/pm/PackageInstaller).
Планирование фоновых задач зависит от
[JobScheduler](https://developer.android.com/reference/android/app/job/JobScheduler)
и [ограничений Doze](https://developer.android.com/training/monitoring-device-state/doze-standby).
