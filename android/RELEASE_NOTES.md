# TG Proxy Android 0.1.9-dev

Dev-сборка для тестирования. Она не отражает финального качества приложения.

- Сохранены подключение Telegram по ссылке, работа прокси в фоне, WSS-маршруты,
  Helper и подписанные обновления.
- Сборка подготовлена через `build-local.ps1 -Delivery` с исходной подписью.
  Для работы с уже загруженными зависимостями добавлен необязательный `-Offline`.
- Проверен переход с оригинальной 0.1.8 без удаления приложения и потери
  зашифрованных настроек, секрета прокси и ключа устройства.

Android 8.0 и новее. Пакет приложения — `io.github.byshadow64.tgproxy`,
versionCode — 11. Для обновления существующей установки нужна прежняя подпись;
удалять приложение или очищать его данные не требуется.

Обновление и работа сервисов проверены на эмуляторах Android 8 и Android 16.
На физических Xiaomi и Samsung эта сборка повторно не проверялась.

В проекте исправлен нестабильный тест общего HTTP-таймаута. Производственный
сетевой код, ограничения времени и закрытие сокетов сохранены. Настольные
маршруты CF/Worker и адреса обновлений не менялись.
