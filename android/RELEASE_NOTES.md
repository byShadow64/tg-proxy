# TG Proxy Android 0.1.11-dev

Dev-сборка для тестирования. Она не отражает финального качества приложения.

- При запросе разрешения на уведомления приложение сохраняет команду запуска,
  даже если Android пересоздал окно.
- Незавершённая настройка SSH показывает кнопки «Продолжить» и «Отменить».
- При новом запуске прокси сбрасывает DNS-кэш, в том числе после смены сети
  при выключенном сервисе.
- Системное подтверждение незавершённой установки можно повторно открыть из приложения.
- Встроенный Helper синхронизирован с общими исходниками. Сборка сверяет его
  файлы и хеши зависимостей Gradle.
- Сохранены CF/Worker, Helper, ссылки Telegram, проверки TLS, подписи APK
  и защита от отката версии. Установку обновления подтверждает пользователь в Android.

Android 8.0 и новее. Пакет приложения — `io.github.byshadow64.tgproxy`,
versionCode — 13. Для обновления существующей установки нужна прежняя подпись;
удалять приложение или очищать его данные не требуется.

Пройдены 200 JVM-тестов и проверка подписи собранного APK. Прежний сертификат
сохранён.

Работа на физических Xiaomi и Samsung, длительный Doze, расход батареи и скорость
медиа в реальном Telegram заново не проверялись.
